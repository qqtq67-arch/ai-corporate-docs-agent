## WF-01 — Загрузка корпоративных регламентов

**Статус: создан в n8n, тестирование ещё не проведено.**

В редакторе n8n на сервере HOSTKEY создан первый процесс **WF-01**. На скриншоте подтверждается наличие **17 рабочих нод и 8 поясняющих Sticky Note**, всего 25 элементов. Соединения визуально присутствуют. Успешная обработка документа, запись в Qdrant и обработка ошибок **пока не подтверждены**.

Технологическая цепочка: **n8n → Apache Tika + Tesseract OCR → Ollama (qwen3-embedding:0.6b) → Qdrant**.

Поддерживаемые форматы по проектной схеме: PDF, DOCX, в том числе сканированные PDF с распознаванием русского текста. Четыре предоставленных заказчиком DOCX-регламента ещё не загружены. PDF с заданием хакатона не входит в корпоративную базу знаний.

Параметры, подлежащие проверке перед первым запуском:
- Tika: **PUT /tika**, заголовки **X-Tika-OCRLanguage: rus+eng** и **Accept: text/plain**.
- Ollama: модель векторизации **qwen3-embedding:0.6b**.
- Qdrant: коллекция **rag_edu_documents_v1**, размерность векторов **1024**.
- Сохранение структуры документа и номеров пунктов для подтверждающих цитат.
- Корректная обработка ошибок и исключение выдачи незавершённой загрузки за успешную.

**Исходный JSON WF-01 в GitHub ещё не сохранён**; репозиторий пока содержит документацию, а не резервную копию workflow.
